# Pixel Rain 🌧️

Matrix-style digital rain rendered on HTML5 Canvas.

![Screenshot](screenshot.png)

## Features

- **Multiple color themes** — Green, Blue, Red, Purple, Rainbow
- **Character sets** — Katakana, Binary, Hex, Alphanumeric
- **Adjustable speed** — Control the rain fall speed
- **Font size control** — Small to large characters
- **Density control** — Sparse to dense rain
- **Glowing trail effects** — Bright lead characters with fading trails
- **Responsive** — Fills the entire viewport

## Usage

Open `index.html` in any modern browser. No build step required.

## Controls

Use the floating panel in the top-right corner to adjust:
- Speed, font size, and density via sliders
- Color theme and character set via buttons
- Click the header to collapse/expand the panel
